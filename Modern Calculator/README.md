# Modern GUI Calculator (C & Raylib)

A graphical user interface (GUI) calculator built entirely in C using the Raylib library. It features a fully interactive visual grid with hover states and standard arithmetic logic.

## Features
* **Standard Arithmetic:** Addition, subtraction, multiplication, and division.
* **Decimal Support:** Floating-point math with trailing zero truncation.
* **State Management:** 'Clear' (C) button and dynamic screen wiping between operations.
* **Interactive UI:** Custom rendering with hover effects and responsive color changes.
* **Memory Safe:** Built-in protection against buffer overflows and division by zero.

## Technologies Used
* **Language:** C
* **Graphics Library:** [Raylib](https://www.raylib.com/)
* **Build System:** Make

## How to Compile and Run

Because this project relies on a C graphics library, you will need a C compiler (like GCC/MinGW) and Raylib installed on your system.

1. **Build the project:**
   This project includes a `Makefile` for easy compilation. Run the following command in your terminal:
   ```bash
   make
   ```
2. **Run the executable**
   ```bash
   ./main
   ```
